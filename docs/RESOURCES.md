# Пересборка ресурсов

`rebuild-resources` структурно пересобирает поддержанные экспорты существующего
пакета. Это не конвертер PNG, FBX или WAV в произвольные игровые ресурсы.
Пакет и все необходимые исходные данные предоставляет пользователь.

```sh
openucc rebuild-resources input.utx output.utx
```

Также обрабатываются поддержанные `.usx`, `.ukx` и `.uax`. Входной и выходной
пути должны быть разными, выходной файл не должен существовать. При обычной
пересборке создаётся незашифрованный Unreal-пакет: исходные ссылки и имена
сохраняются с переносом поддержанных смещений. Если формат, класс, данные или
профиль не поддерживаются, команда сообщает об ошибке и не создаёт результат.

Профиль записан как `version/licensee`. Поддержка контейнера не означает
поддержку любого объекта внутри него: все экспорты должны соответствовать
реализованным форматам и проверкам.

## Поддерживаемые типы

- Texture, Palette, Font, Cubemap, MaskTexture, WetTexture, пустые группы
  Package и поддерживаемые классы материалов. Доступность конкретного типа
  зависит от профиля. Для текстур поддерживаются только реализованные варианты
  формата и структуры mip-уровней; неизвестные поля и хвосты отклоняются.
- StaticMesh: `118/0`, `123/{12,14,15,16,18,19,20,22,23,25,28,31,33,35,36,37,38}`,
  `125/38–39`, `126–128/39` и `130–133/40`.
- SkeletalMesh: `123/36`, `131/40`, `132/40`, `133/40` и версии LodMesh 5–7.
  VertMesh: `123/37` и `133/40`.
- MeshAnimation версии 1: `123/36`, `131/40`, `133/40`. Для поддерживаемых
  профилей также обрабатываются отдельные классы уведомлений анимации.
- Sound в формате WAV: `123/23`, `128/39`, `130/40`, `131/40`, `133/40`.
  Аудиобайты сохраняются без перекодирования.
- Model: поддерживаемые структуры `123/37` и `133/40`; для `127/39`, `128/39`,
  `130/40` и `132/40` реализована только ограниченная форма с пустыми
  дополнительными массивами. Polys и KMeshProps также имеют ограничения по
  профилю и содержимому. Поддержка отдельных Model не означает полной
  пересборки карт.

Для SkeletalMesh, VertMesh и MeshAnimation проверяются границы и наличие
неподдержанных хвостов. Сохранение структуры не подтверждает корректность
рендеринга, коллизии или воспроизведения анимации и звука.

### Unverified Model fallback

Если структура Model не подтверждена, а все остальные экспорты прошли проверки,
команда выдаёт предупреждение и возвращает JSON со значениями
`status: unchanged_copy` и `reconstruction_performed: false`. В этом случае
**весь пакет копируется без изменений**: ресурсы не пересобираются, ссылки и
смещения не переносятся. Другая ошибка по-прежнему приводит к отказу без записи.

Для `Lineage2Ver121` ключ зависит от имени файла. При таком копировании сохраните
исходное имя: изменение имени сопровождается предупреждением и может сделать
копию нечитаемой.

## Проверка контейнера

`openucc roundtrip input.u` проверяет чтение и повторную запись контейнерных
таблиц и содержимого экспортов без создания файла. Дополнительный аргумент
задаёт новый выходной файл. Это не доказывает корректности внутренних смещений
неизвестных ресурсов и не заменяет проверку результата в целевом окружении.
